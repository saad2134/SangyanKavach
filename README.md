## 🏃 Running the Application

### 1. Install Dependencies
```bash
npm install
```

### 2. Launch Local Dev Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser. The application initializes with **Scenario 01 (Telegram VIP Multi-Bagger Pump)** pre-loaded for immediate live forensic evaluation.

### 3. Production Build
```bash
npm run build
npm run preview
```
